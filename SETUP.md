# Перший запуск сайту Nelli

Сайт працює на GitHub Pages. Google Apps Script виконує роль тимчасового backend, Google Sheets зберігає базу, а Google Drive — фотографії. Сервер сайту не потрібен.

## 1. Створіть Google Apps Script

1. Відкрийте [script.google.com](https://script.google.com/) у своєму Google-акаунті й створіть новий проєкт.
2. Відкрийте файл `apps-script/Code.gs` з цього архіву, скопіюйте весь його вміст і замініть ним код у файлі `Code.gs` редактора Apps Script.
3. У списку функцій виберіть `setupNelliDrive` і натисніть **Run**. Підтвердьте запит доступу від Google.
4. Відкрийте **Execution log**. Функція створить таблицю та папку у вашому Google Drive і виведе приватний ключ адмінки. Збережіть ключ у приватному місці. Не додавайте його до `config.js` і не надсилайте в чат.

Перший запуск створює окрему таблицю й папку. Він не змінює та не видаляє вашу стару таблицю, стару папку або файли. Старі записи автоматично не копіюються.

## 2. Опублікуйте backend

1. У Apps Script виберіть **Deploy → New deployment**.
2. Тип: **Web app**.
3. **Execute as:** Me.
4. **Who has access:** Anyone. Це потрібно, щоб публічний сайт міг прочитати опубліковане портфоліо й записати заявки. Адмінські дії окремо захищені приватним ключем, який зберігається у властивостях Apps Script.
5. Натисніть **Deploy** і скопіюйте URL, що закінчується на `/exec`.

## 3. Під’єднайте сайт до backend

У `config.js` замініть текст `PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE` на скопійований `/exec` URL. Сам URL не є паролем; приватний ключ у цей файл не вставляйте.

Потім завантажте файли сайту в GitHub-репозиторій і дочекайтеся завершення публікації GitHub Pages. Для оновлення використовуйте папку `nelli-site-main` з архіву як корінь репозиторію.

## 4. Почніть користуватися

- Адмінка: `https://ВАШ-АКАУНТ.github.io/nelli-site/admin/`
- Публічний сайт: `https://ВАШ-АКАУНТ.github.io/nelli-site/`
- Увійдіть за приватним ключем з Execution log.
- Створіть фотосесію, заповніть назву та збережіть її.
- Додайте фотографії. Позначте фотосесію як видиму й збережіть ще раз, щоб показати її на сайті.
- У вкладці **Тексти сайту** відредагуйте потрібні мови. Спершу можна зберегти чернетку; кнопка **Опублікувати зміни** показує її відвідувачам.
- Заявки з контактної форми з’являються у вкладці **Заявки** та в аркуші `Requests` таблиці Google.

Після кожного збереження адмінка повторно читає дані з Google Sheets. Вона показує успіх тільки після підтвердження зміни сервером.

## Зберігання старих даних

Старий Apps Script-код і ID таблиці/папки не були в наданому ZIP. Новий backend не має способу безпечно визначити, до яких старих файлів він має під’єднатися, тому він створює окрему структуру у вашому Drive і залишає стару недоторканою. Якщо потрібно продовжити роботу саме з наявною таблицею та фотопапкою, підставте їхні ID у **Project Settings → Script Properties** до `setupNelliDrive()` (`SPREADSHEET_ID` та `PHOTO_FOLDER_ID`). Таблиця має містити окремі аркуші `Sessions`, `Photos`, `Requests` і `SiteContent` із заголовками з `apps-script/Code.gs`; старі рядки автоматично не перетворюються.

## Тимчасова модель доступу

Сторінка `/admin/` публічна, але ключ перевіряється на Apps Script. Публічний сайт може читати лише опублікований контент; для завантаження, зміни чи видалення потрібен ключ. Сесія входу завершується після закриття сторінки або натискання **Вийти**. Під час публікації фото з видимих фотосесій доступні відвідувачам сайту через публічні посилання Google Drive.
